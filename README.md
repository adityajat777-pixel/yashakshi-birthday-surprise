# A Birthday Surprise for Yashakshi

A polished, mobile-first birthday experience made especially for Yashakshi. The page guides her through a playful sequence with a yes/no branch, a dark-to-light reveal, an uploaded piano soundtrack, decorations, flying balloons and emojis, an animated cake, and a long personal letter that scrolls at a comfortable reading pace.

## Technology

- TanStack Start
- React 19 and TypeScript
- Vite
- Tailwind CSS foundation with custom CSS animation
- Lucide icons
- Netlify deployment

## Run Locally

1. Install dependencies with `pnpm install`.
2. Start the development server with `pnpm dev`.
3. Open the local URL shown in the terminal.

## Main Files

- `src/routes/index.tsx` — story flow, controls, message, and effects
- `src/styles.css` — responsive visual design and animation
- `public/audio/birthday-piano.mp3` — birthday soundtrack

The experience is self-contained and requires no environment variables or database.
